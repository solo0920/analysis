# 分析師備考站

為「證券投資分析人員考試」整理的靜態學習網站，分成 **總體經濟學**、**投資學**、**會計學** 與 **證券交易相關法規與實務** 四個獨立科目，並附 **107–115 年歷屆考古題練習庫**。各科章節另整合 107–115 年計算／申論題與代表性選擇題的解題過程，以「讀完即可解題」為主。沒有前端框架、沒有後端；效能分包由 Node 腳本事先產生，所有內容都存在 JavaScript／分包檔，直接開啟 `index.html` 也能閱讀。全站中文採臺灣繁體中文；英文只保留得主姓名、專有名詞、公式符號、縮寫與技術名稱。

四個科目各自成篇，不共用章節：

- 總體經濟學使用 `gross_economics_contents.md` 的 Parts 1–2（Part 1「總體經濟學」第 1–10 章、Part 2「金融市場」第 11–13 章）；Part 2 仍屬總體經濟學科目，不與投資學共用。
- 投資學只使用 `investment_contents.md` 的 Parts 1–5，不使用總體經濟學的章節（包含其 Part 1 與 Part 2）。
- 投資學來源沒有第十二章，網站保留第十一章到第十三章之間的編號跳號，不自行補章。
- 投資學來源只提供 Part 起始頁，沒有各章頁碼；畫面顯示的是 Part 頁碼，不是推測的章頁碼。
- 投資學來源沒有節名；章內單元標為「學習重點」，不冒充原書的「第 N 節」。
- 會計學使用 `accounting_toc.md` 的第 1–23 章；第 1–7、12–15、20 章有來源節名，依原順序呈現，其餘章節只列章名，章內單元標為「學習重點」。財務分析總架構、杜邦分析與四表連結的圖表內容參考 `accounting_contents.md`，分別掛在 `accounting-15#0`、`accounting-15#1`、`accounting-23#1`。
- 會計學第 23 章來源註明原書章號印刷為 22，本站依順序列為第 23 章，並在章節與使用說明保留註記。
- 證券交易相關法規與實務依 `ExamScope.md` 的 21 項測驗範圍整理為 21 頁；官方 15 部法規逐條呈現（1,507 條），公會自律規範與「其他主管機關法令」以官方連結與摘要呈現；法規適用仍以全國法規資料庫與主管機關最新公告為準。
- 歷屆考古題練習庫收錄 107–115 年共 29 次筆試、四個專業科目的 3,710 題選擇題；題目與官方選擇題解答分開保存，練習時先作答再看答案；每題以 `sourceIds` 標示一個或多個章節出處與考試次別，章節頁列出該章出現的年份／次別，科目頁顯示各章出題次數與頻率。另收錄 107–115 年四科 348 題計算／申論題，348 題全部為參考解答，並逐題檢核是否完整回答題幹子題；官方解答 PDF 只有選擇題答案，故不宣稱參考解答或逐選項解析為官方答案。107–115 年計算／申論題與代表性選擇題的解題過程另整合進各科章節（`window.EXAM_SOLUTIONS`），以 `chapterId::sectionIndex` 綁定，合計 347 節次、601 個例題（348 題計算／申論＋253 題代表選擇題）。
- 考古題以證基會公告的選擇題解答為準；115 年第 1、2 次直接連結證基會官方檔案，107–114 年因官方頁面只保留近期試題，試題連結公開題庫鏡像；107–108 年解答連結公開文字版 PDF，109–114 年解答連結鏡像 PDF，並在每次考試保留試題與解答連結供對照。
- 107–108 年已納入自動練習庫：選擇題解答由使用者提供的逐題轉錄檔（MD／JSON）匯入，並與公開解答 PDF 及原始 JPG 解答抽查核對；兩題官方接受多個答案（108Q3 法規第 28 題 C、D；108Q3 會計第 28 題 B、D）已保留。
- 考古題出處以章節為單位：每題的 `sourceId` 指向同一科目的章節，題目卡可直接連到該章內容；章節頁列出 107–115 年出現的考試次別與題數。科目首頁的章節列顯示「出題次數」與「頻率」，頻率＝該章題數 ÷ 該科總題數。出處依題幹、選項與章節內容比對後建立，作為複習導覽，不代表官方命題分類。

目前規模：4 個科目、73 章、229 個學習單元、1,513 張名詞卡、118 組學習單元 KaTeX 公式（另含比例 32 條、核心公式 66 條、技術指標 50 種、選擇權 30 條、諾貝爾 58 屆）、1,507 條官方法規條文列（含刪除條文）、38 張章節教學圖（總體經濟 22、投資學 9、會計學 7）、32 條投資學比例分析公式、66 條投資學核心公式、50 種技術分析指標、7 項選擇權評價優先順序、58 屆諾貝爾經濟學獎年表、17 組諾貝爾模型圖、1 個總體經濟學派演進圖（6 階段、10 個節點、19 個模型連結、15 個諾貝爾里程碑）、29 個資料來源、29 次考古題（3,710 題，全部標示章節出處與出題頻率）、348 題計算／申論題（107–115 年，全部提供完整參考解答）、107–115 年章節解題（347 節次、601 個例題：348 題計算／申論＋253 題代表選擇題）與 1 個總經時事頁、1 個考前猜題頁（97 題組／118 個部分、五個科目分頁、21 組多部分題組、38 條整合公式、DCF／債券敏感度矩陣、13 個章節進階補給）；並有 1 個總體經濟模型總覽頁、1 個學派演進圖區塊、1 個諾貝爾獎年表頁、1 個投資學公式總表頁、1 個考古題練習庫。總體經濟 21 張既有模型圖與 29 條投資／總體公式已完成公開教材核對，狀態為「通過（教材）」；另 1 張新增國民所得會計帳流程圖、投資學 9 張教學圖與會計學 7 張教學圖（會計循環、主要財務報表架構、借記／貸記常用項目、交易到報表流程、財務分析總架構、杜邦分析、四表連結）為依教材概念繪製的示意圖，已通過結構與章節綁定驗證，尚未逐條對照公開教材。這不是官方認證整站。

## 本機預覽

建議用靜態伺服器：

```bash
python3 -m http.server 8765 --directory site
```

開啟 <http://localhost:8765/>。

也可以直接開啟 `site/index.html`。內容全部內嵌，不需要 `fetch`，所以 `file://` 可正常顯示；只有外部資料來源連結需要網路。

## GitHub Pages

線上網站：<https://solo0920.github.io/analysis/>

`.github/workflows/pages.yml` 會在推送 `main` 時將 `site/` 上傳為 Pages artifact，再以 `actions/deploy-pages` 發佈。`site/.nojekyll` 停用 Jekyll 處理，`site/404.html` 會將未知路徑導回站點根目錄；所有資產使用相對路徑，可直接在 `/analysis/` 子路徑下運作。

Repository 的 Pages Source 已設為 **GitHub Actions**；若之後重新建立 Pages，請在 Repository Settings → Pages 將 Source 設為 **GitHub Actions**。

## 設計限制

- 靜態網站、無建置步驟、無外部套件。
- 模型圖是概念示意，用於理解曲線方向與移動，不提供互動拖曳、數值模擬或實證估計。
- 模型總覽頁是唯讀聚合視圖，不是另一份內容或線上編輯器；更新來源仍是 `diagrams-macro*.js`，變更後重新載入即可在章節頁與總覽頁看到同步結果。
- 窄螢幕下模型圖保留最小寬度，可在圖表區塊內水平滑動，並顯示「圖表較寬」提示；頁面本身不會水平溢出。
- 章節進度存在 `localStorage`，鍵名為 `analyst-prep-progress-v2`；考古題作答存在 `analyst-past-exam-progress-v1`；主題鍵名為 `analyst-theme`。投資學章節已重建，因此不使用舊版 `v1` 章節進度，避免舊章節 ID 對應到新章節。
