國民所得與經濟福祉

建立國民所得會計的基本語言：GDP 怎麼定義、怎麼算、怎麼衡量物價與成長，以及為什麼 GDP 不能直接等同於經濟福祉。

第 1 節

國民所得與GDP

國民所得會計是總體經濟學的起點。GDP（國內生產毛額）衡量一國境內在一定期間內所生產的最終財貨與勞務的市場價值，探討的是「在哪裡生產」；GNP（國民生產毛額）或 GNI（國民總收入）則以本國居民為原則，探討「誰的生產所得」。

第 2 節

GDP之計算

GDP 有三種計算方式：支出面、所得面與生產面。理論上三者應相等，但實務上因統計誤差而略有差異。支出面法最常用，把最終支出拆成消費、投資、政府支出與淨出口。

第 3 節

其他國民所得衡量工具

完整的國民所得會計帳可以從 GNI 一路推到個人可支配所得（PDI）。先由支出面的 GDP = C + I + G + (X - M) 出發，加上國外要素所得淨額 NFIA，得到 GNI = GDP + NFIA ；再扣固定資本消耗（折舊）D，得到 NNP = GNI - D ；最後扣間接稅淨額 NIT，得到 NI = NNP - NIT 。

第 4 節

物價指數與經濟成長率

物價指數是將一籃商品與服務的當期成本除以基期成本，再乘以100。依權數（數量）固定在基期或當期，常用拉氏指數與帕氏指數；兩者都可以用來衡量物價，但權數不同，對通膨的解釋也不同。

第 5 節

國民所得做為經濟福利指標的問題

GDP 衡量的是市場交易價值，但經濟福利還包括所得分配、休閒、環境品質、健康、教育與家庭生產。GDP 增加不一定代表生活變好，GDP 下降也不一定代表福利變差。

名詞速查

國內生產毛額（GDP）

一國境內在一定期間內生產之最終財貨與勞務的市場價值，採屬地原則。

國民生產毛額（GNP）／國民總收入（GNI）

本國居民在一定期間內生產所得，採屬人原則；GNP=GDP+GNP = GDP +GNP=GDP+ 國外要素所得淨額。

最終財貨

供最終消費、投資或出口使用，不再進入生產流程的財貨，計算 GDP 時只計最終財貨以避免重複計算。

名目 GDP 與實質 GDP

名目 GDP 以當期價格計算；實質 GDP 以固定基期價格計算，排除物價變動的影響。

支出面法

由最終需求出發：GDP = 消費 + 投資 + 政府支出 + 出口 − 進口。

所得面法

由生產要素報酬加總：工資、租金、利息、利潤，再加間接稅淨額與折舊等調整項。

生產面法（價值增加法）

各產業產值減去中間投入後的價值增加，加總即為 GDP。

存貨投資

期末存貨減期初存貨；存貨增加視為投資增加，存貨減少則扣減。

國民生產毛額（Gross National Product, GNP）／國民總收入（Gross National Income, GNI）

以本國居民為原則的生產所得；GNI=GDP+NFIAGNI = GDP + NFIAGNI=GDP+NFIA。多數教材將 GNP 與 GNI 視為同義，臺灣官方近年多用 GNI。

國外要素所得淨額（Net Factor Income from Abroad, NFIA）

本國居民在國外生產所得減外國居民在本國生產所得；可正可負，是 GDP 與 GNI 的橋樑。

國民生產淨額（Net National Product, NNP）

GNI 減固定資本消耗（折舊）：NNP=GNI−DNNP = GNI - DNNP=GNI−D，反映資本折耗後的生產淨額。

固定資本消耗／折舊（Consumption of Fixed Capital, CFC／Depreciation, D）

生產過程中資本設備的耗損；是 GNI 推導 NNP 的扣項，不是要素報酬。

國民所得（National Income, NI）

NNP 減間接稅淨額：NI=NNP−NITNI = NNP - NITNI=NNP−NIT；衡量生產要素報酬的總和，又稱按要素成本計算的國民所得。

間接稅淨額（Net Indirect Taxes, NIT）

間接稅減補貼：NIT=Ti−SuNIT = T_i - S_uNIT=Ti​−Su​；從市場價格的 NNP 轉為要素成本的 NI 時扣除。

個人所得（Personal Income, PI）

家計單位在收到個人直接稅前的所得：PI=NI−CIT−URE−SSC+TR+INTPI = NI - CIT - URE - SSC + TR + INTPI=NI−CIT−URE−SSC+TR+INT。

營利事業所得稅（Corporate Income Tax, CIT）

公司利潤先繳給政府的稅；計算 PI 時從 NI 扣除，因為它不是家計單位可收到的所得。

未分配盈餘（Undistributed Corporate Profits／Retained Earnings, URE）

公司保留下來、未發給股東的利潤；計算 PI 時扣除。

社會安全捐（Social Security Contributions, SSC）

受僱者與雇主繳交的社會安全制度費用；計算 PI 時扣除。

移轉支付（Transfer Payments, TR）

政府或企業無對價給付給個人的款項，如社會福利、失業救濟；不計入 GDP／NI，但計入 PI。

淨利息（Net Interest, INT）

家計單位收到的利息與支付的利息淨額（含政府公債利息等）；計算 PI 時加回。

個人直接稅（Personal Direct Taxes, Tp）

個人所得稅、財產稅等直接由個人負擔的稅；從 PI 扣除後得到 PDI。

個人可支配所得（Personal Disposable Income, PDI）

個人真正可以自由支配的所得：PDI=PI−Tp=C+SPDI = PI - T_p = C + SPDI=PI−Tp​=C+S；英文亦常作 Disposable Personal Income（DPI）。

消費（Consumption, C）

家計單位對最終財貨與勞務的支出；是 PDI 的主要用途。

儲蓄（Saving, S）

PDI 中未用於消費的部分：S=PDI−CS = PDI - CS=PDI−C。

消費者物價指數（CPI）

以固定消費籃比較當期與基期成本，通常接近拉氏指數，是衡量通膨最常用的指標；CPI 包含進口消費品。

（本期實質 GDP − 上期實質 GDP）÷ 上期實質 GDP × 100%。

地下經濟

未申報、未登記或非法的經濟活動，通常不計入官方 GDP。

外部成本

生產或消費對第三方造成、未反映在市場價格中的成本，如污染。

所得分配

GDP 總量無法反映所得集中程度；相同 GDP 可能有不同分配結果。

綠色 GDP／福利指標

將環境耗損、休閒與所得分配等因素納入調整後的衡量概念。

考試重點

  • GDP 不計入中間財、二手交易與純移轉性支付。
  • 外籍移工在臺生產計入臺灣 GDP；臺商海外生產不計入臺灣 GDP。
  • GDP 是流量概念，衡量一段期間的生產，不是國家財富存量。
  • 進口不計入 GDP，出口計入 GDP；淨出口可為負。
  • 政府移轉性支出（如救濟金）不屬於政府購買，不計入 GDP。
  • 折舊與間接稅是所得面法的重要調整項，方向常考。
  • GNI 與 GNP 多數教材同義；GDP 採屬地、GNI 採屬人，兩者以 NFIA 連接。
  • GNI→NNP 扣折舊 D；NNP→NI 扣間接稅淨額 NIT（間接稅減補貼）。
  • NI→PI 的扣項是 CIT、URE、SSC；加項是 TR、INT，方向不要顛倒。
  • 移轉支付不是當期生產，不計入 GDP 與 NI，但它是 PI 的加項。
  • PI 是個人稅前所得；PDI 是個人稅後可支配所得，兩者不同。
  • PDI = C + S；消費函數以 PDI 為主要解釋變數，儲蓄是 PDI 減消費。
  • 人均所得＝國民所得 ÷ 人口，常用於跨國生活水準比較；它仍是平均數，不能反映所得分配。
  • 拉氏指數固定基期數量；帕氏指數使用當期數量，權數會隨期間改變。
  • 拉氏指數常高估、帕氏指數常低估通膨，差異主要來自替代偏誤。
  • GDP 平減指數是帕氏型，使用當期數量；CPI 通常是固定籃，較接近拉氏型。
  • GDP 平減指數不含進口品；CPI 則包含進口消費品。
  • 物價指數上升不等於通膨率上升；通膨率是物價指數的百分比變動。
  • 經濟成長率用實質 GDP 計算，名目 GDP 成長可能只是物價上漲造成的虛增。
  • GDP 不包含家務、志工、休閒與地下經濟。
  • 污染、災害與重建可能同時推高 GDP，卻降低福利。
  • GDP 高不等於幸福高；所得分配與環境品質同樣重要。

本章公式

  • GDP = C + I + G + (X − M)
  • GDP = C + I + G + X − M
  • GNI = GDP + NFIA；NNP = GNI − D；NI = NNP − NIT；PI = NI − CIT − URE − SSC + TR + INT；PDI = PI − Tp = C + S
  • 實質 GDP = 名目 GDP ÷（GDP 平減指數 ÷ 100）；拉氏指數用基期數量，帕氏指數與 GDP 平減指數用當期數量
