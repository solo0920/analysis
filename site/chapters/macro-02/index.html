簡單凱因斯所得模型

用有效需求與乘數效果解釋短期所得如何決定，並理解政府支出、租稅與節儉的矛盾。

本章導讀

第 1 節

均衡所得之決定

簡單凱因斯模型假設物價、利率與投資固定，短期產出由總支出決定。當總支出等於總產出時，經濟達到均衡；若支出不足，存貨增加，廠商減產，所得下降。

第 2 節

政府收支與反景氣循環之財政政策

政府可以透過支出與租稅調節總需求。景氣衰退時採擴張性財政政策，增加支出或減稅；景氣過熱時採緊縮性財政政策，減少支出或增稅。

第 3 節

節儉的矛盾

節儉的矛盾是指：個人增加儲蓄雖是美德，但若全體同時增加儲蓄，消費與總需求下降，所得減少，最後總儲蓄未必增加。這是凱因斯對緊縮經濟的主張。

名詞速查

有效需求

實際支出所形成的需求，凱因斯認為短期產出與就業由有效需求決定。

邊際消費傾向（MPC）

所得增加一元時，消費增加的金額；0 < MPC < 1。

邊際儲蓄傾向（MPS）

所得增加一元時，儲蓄增加的金額；MPS = 1 - MPC。

自發性支出

不隨所得變動的支出，如自發性消費、投資、政府支出與出口。

乘數

自發性支出變動引起均衡所得變動的倍數；封閉經濟下為 1 ÷ (1 − MPC)。

擴張性財政政策

增加政府支出或減稅，刺激總需求與所得。

緊縮性財政政策

減少政府支出或增稅，抑制總需求與通膨。

自動穩定機制

所得稅、失業救濟等隨景氣自動調節，不需另行立法。

裁量性財政政策

政府主動改變支出或稅率，以因應景氣變化。

排擠效果

政府借款推高利率，減少民間投資，削弱財政政策效果。

特別預算

為特定重大事項另編的預算，仍需立法程序與財政規範。

節儉的矛盾

全體增加儲蓄導致總需求下降、所得減少，儲蓄未必增加。

儲蓄悖論

與節儉的矛盾同義，強調個體理性與總體結果的衝突。

緊縮缺口

均衡所得低於充分就業所得時的差距。

消費不足

總需求低於充分就業產出，導致失業與產能閒置。

考試重點

  • 均衡條件為 Y = C + I + G + NX，或總支出等於總產出。
  • MPC 越大，乘數越大；MPS 越大，乘數越小。
  • 緊縮缺口是均衡所得低於充分就業所得；膨脹缺口則相反。
  • 政府支出乘數 = 1/(1 − MPC)；租稅乘數 = −MPC/(1 − MPC)。
  • 平衡預算乘數 = 1，表示政府支出與租稅等額增加時，所得仍會增加。
  • 景氣循環調整後預算餘額（結構性預算）比實際預算更能反映財政立場。
  • 未充分就業時，增加儲蓄可能使所得與儲蓄同時下降。
  • 充分就業時，儲蓄增加可支持投資，不一定有害。
  • 長期成長仍取決於資本累積、技術進步與制度。

本章公式

  • Y = 1/(1 − MPC) × A₀（A₀ 為自發性支出；封閉、無稅、無進口、物價固定的簡單模型）
  • 政府支出乘數 = 1/(1 − MPC)；定額稅租稅乘數 = −MPC/(1 − MPC)
