利率

第 1 節

利率基本概念與利率類型

利率是使用資金的價格，也是把未來現金流換算成現值的折現率。名目利率未調整通膨，實質利率則扣除預期通膨，反映資金實際購買力的報酬。

第 2 節

利率決定理論

可貸資金理論從可貸資金的供給與需求決定利率。供給來自儲蓄、貨幣供給與國外資金；需求來自投資、政府赤字與消費借貸。供給增加使利率下降，需求增加使利率上升。

第 3 節

利率之風險結構

風險結構探討相同到期日、不同債券之間的利率差異。違約風險、流動性、租稅與嵌入式選擇權都會造成利差；信用評等越差，投資人要求的風險溢酬越高。

第 4 節

利率之期限結構理論

期限結構描述相同信用風險下，不同到期日債券的殖利率關係，畫成圖形即為收益率曲線。收益率曲線可能上升、平坦或倒掛。

第 5 節

利率風險管理

利率變動會造成債券價格與再投資報酬變動。存續期間衡量價格對利率的敏感度，修正存續期間可估算殖利率變動對價格的百分比影響，凸性則修正大幅利率變動的誤差。

名詞速查

利率

使用資金的價格，也是未來現金流的折現率。

名目利率

未調整通貨膨脹的利率。

實質利率

扣除預期通膨後的利率，反映購買力報酬。

費雪效果

名目利率約等於實質利率加預期通膨率。

即期利率

從現在到某一到期日的實際折現率。

遠期利率

未來某一段期間的隱含利率，可由即期利率推導。

重貼現率

銀行向央行貼現借款的利率，具政策宣示效果。

金融業拆款利率

金融機構之間短期資金借貸的利率。

美國國債

美國財政部發行的債務工具，其規模與殖利率影響全球資金成本。

聯準會主席

美國聯邦準備理事會最高負責人，其政策立場影響全球利率預期。

可貸資金理論

以可貸資金供給與需求決定利率的理論。

流動性偏好理論

凱因斯認為利率由貨幣供給與貨幣需求共同決定。

可貸資金供給

儲蓄、貨幣供給增加與國外資金流入等資金來源。

可貸資金需求

投資、政府赤字與消費借貸等資金用途。

費雪效果

預期通膨上升會推高名目利率，實質利率長期相對穩定。

預期通膨

市場對未來物價上漲的預期，會影響名目利率。

利率風險結構

相同期限下，不同債券因風險與特性不同而產生殖利率差異。

違約風險

發行人無法按時支付利息或本金的風險。

流動性風險

債券不易快速變現或以合理價格交易的風險。

租稅效果

利息所得稅負不同，會造成債券殖利率差異。

信用價差

公司債殖利率與同期限無風險利率的差額。

信用評等

信用評等機構對發行人或債券違約風險的評分。

期限結構

相同信用風險下，不同到期日與殖利率之間的關係。

收益率曲線

以到期日為橫軸、殖利率為縱軸的曲線。

預期理論

長期利率等於未來短期利率預期的平均。

流動性溢酬理論

長債風險較高，需提供額外流動性溢酬。

市場區隔理論

不同期限市場由不同投資人與資金供需決定。

偏好棲息地理論

投資人有偏好期限，但若溢酬足夠仍可能改變期限。

殖利率曲線倒掛

短期利率高於長期利率，常被視為景氣衰退的領先訊號。

存續期間

債券現金流加權平均到期時間，衡量價格對利率的敏感度。

修正存續期間

Macaulay 存續期間除以 (1 + y/k)，估算殖利率變動對價格的影響。

凸性

價格與殖利率關係的曲度，修正存續期間對大幅利率變動的誤差。

免疫策略

調整資產現值與存續期間以匹配負債，降低利率風險。

利率交換

交換固定利率與浮動利率現金流的契約。

利率期貨

以利率或債券價格為標的的期貨契約，用於避險或投機。

再投資風險

利息再投資時利率下降的風險。

價格風險

利率上升造成債券價格下跌的風險。

考試重點

  • 預期通膨上升通常推高名目利率。
  • 實質利率是投資與儲蓄決策的關鍵變數。
  • 不同利率的差異反映風險、流動性與期限。
  • 可貸資金供給增加，均衡利率下降；需求增加，均衡利率上升。
  • 貨幣供給增加短期壓低利率，但長期可能因通膨預期而推高名目利率。
  • 政府赤字增加會提高可貸資金需求，可能產生排擠效果。
  • 違約風險越高，投資人要求的殖利率越高。
  • 流動性越差、稅負越不利，殖利率通常越高。
  • 信用價差擴大常是景氣惡化與風險升高的訊號。
  • 收益率曲線上升通常代表景氣擴張與通膨預期。
  • 倒掛可能反映緊縮政策與景氣降溫預期。
  • 不同理論對長短期利率關係的解釋不同，考試常比較其差異。
  • 存續期間越長，利率風險越大。
  • 修正存續期間適用於小幅利率變動；大幅變動需加入凸性。
  • 免疫策略可降低利率風險，但仍需動態調整。

本章公式

  • 實質利率 ≈ 名目利率 − 預期通膨率；精確式：1 + 名目利率 = (1 + 實質利率) × (1 + 預期通膨率)
  • 可貸資金均衡：可貸資金供給 = 可貸資金需求
  • 債券殖利率 ≈ 無風險利率 + 違約風險溢酬 + 流動性溢酬 + 其他溢酬
  • (1 + yn)ⁿ = (1 + y₁)(1 + f₂)…(1 + fn)（yn 為 n 期即期年化利率；ft 為第 t 期一年期隱含遠期利率；相同複利與期間單位，無套利）
  • 修正存續期間 D* = D ÷ (1 + y/k)；價格變動率 ≈ −D* × Δy + ½ × 凸性 × (Δy)²（D 為 Macaulay 存續期間（年）、y 為年化殖利率、k 為每年付息次數；Δy 與凸性採相同週期，Δy 用小數）
